# B105 Statistical Modelling Project

Statistical analysis of an e-commerce sales dataset using RStudio.

## Project Files
- `data/`: Sales transactions dataset.
- `scripts/`: R scripts for data exploration, hypothesis testing, and regression models.
- `ASSIGNMENT105.Rproj`: RStudio project file.

## How to Run
Open `ASSIGNMENT105.Rproj` in RStudio and run any script in the `scripts/` folder.
